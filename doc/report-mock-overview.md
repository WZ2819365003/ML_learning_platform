## 结论

xgboost_regressor 表现最好，交叉验证 RMSE 72.5，相当于把 8897 的平均负荷预测偏差 0.8%。lightgbm 只差 0.3——这个差距比模型自身的折间波动还小，两者其实分不出高下。三个深度学习模型的误差是树模型的两倍，明显落后。

这批 Run 用的是随机切分。数据里有滞后特征，随机切分会让"未来"混进训练，所以上面的分数比真实上线时乐观。下一步：<<豆包一句>>
