# 深度学习模块设计方案 — v2.0.0

**日期**: 2026-04-09  
**分支**: feat/dl-module  
**前置版本**: v1.1.0（15 模型注册表 + ModelSelector + DynamicParamForm）

---

## 一、目标与范围

在现有 ML 平台基础上，新增一套独立的"深度学习"模块，与机器学习模块并列。核心诉求：

| 诉求 | 说明 |
|------|------|
| 独立导航 | 侧边栏新增"深度学习"入口，与"训练管理"分开 |
| 模型覆盖 | Transformer、LSTM、CNN-1D、MLP-DL（含 GRU） |
| Dropout 配置 | 每个模型可独立配置 dropout rate |
| 优化器选择 | Adam / AdamW / SGD / RMSProp，含完整超参 |
| 实时监控 | WebSocket 推送 epoch 级别 loss/acc 曲线 |
| GPU 支持 | 自动检测 CUDA，CPU 降级兜底 |
| 任务类型 | 分类 & 回归均支持 |

## 三、数据库设计

### 3.1 新表：DLTrainingTask

```python
class DLTrainingTask(Base):
    __tablename__ = "dl_training_tasks"

    id            = Column(String, primary_key=True, default=lambda: str(uuid4())[:12])
    dataset_id    = Column(String, ForeignKey("datasets.id"), nullable=False)
    target_column = Column(String, nullable=False)
    model_type    = Column(String, nullable=False)       # mlp_dl / cnn1d / lstm / transformer
    task_type     = Column(String, default="classification")  # classification / regression

    # 训练配置（JSON）
    arch_config   = Column(JSON, default={})   # 网络结构参数
    opt_config    = Column(JSON, default={})   # 优化器参数
    train_config  = Column(JSON, default={})   # epochs / batch_size / scheduler 等

    # 状态
    status        = Column(String, default="PENDING")  # PENDING/RUNNING/SUCCESS/FAILED
    progress      = Column(Float, default=0.0)         # 0–100
    current_epoch = Column(Integer, default=0)
    total_epochs  = Column(Integer, default=0)

    # 结果
    result_metrics = Column(JSON, nullable=True)
    model_path     = Column(String, nullable=True)
    error_message  = Column(String, nullable=True)

    created_at  = Column(DateTime, default=lambda: datetime.now(timezone.utc))
    started_at  = Column(DateTime, nullable=True)
    finished_at = Column(DateTime, nullable=True)
```

## 五、各模型参数规格

### 5.1 公共优化器参数（所有 DL 模型共享）

| 参数 | 类型 | 默认 | 说明 |
|------|------|------|------|
| optimizer | str enum | "adam" | adam / adamw / sgd / rmsprop |
| learning_rate | float | 0.001 | 学习率 |
| weight_decay | float | 0.0 | L2 正则（AdamW 时为解耦 WD） |
| beta1 | float | 0.9 | Adam/AdamW 一阶矩系数（高级） |
| beta2 | float | 0.999 | Adam/AdamW 二阶矩系数（高级） |
| momentum | float | 0.9 | SGD/RMSProp 动量（高级） |

### 5.2 公共训练参数（所有 DL 模型共享）

| 参数 | 类型 | 默认 | 说明 |
|------|------|------|------|
| epochs | int | 50 | 最大训练轮数 |
| batch_size | int | 32 | 每批样本数 |
| test_size | float | 0.2 | 测试集比例 |
| early_stopping_patience | int | 10 | 验证集无改善时提前停止 |
| grad_clip | float | 1.0 | 梯度裁剪最大范数（高级） |
| scheduler | str enum | "none" | none / step / cosine / plateau（高级） |

### 5.3 MLP-DL 结构参数

| 参数 | 类型 | 默认 | 说明 |
|------|------|------|------|
| hidden_layers | list | [256, 128] | 各隐藏层神经元数，逗号分隔 |
| dropout | float | 0.3 | 每层后 Dropout 概率 |
| batch_norm | bool | True | 是否添加 BatchNorm |
| activation | str enum | "relu" | relu / gelu / tanh / leaky_relu |

### 5.4 CNN-1D 结构参数

> 将每个特征视作序列的一个"时间步"，适合表格数据的特征交互。

| 参数 | 类型 | 默认 | 说明 |
|------|------|------|------|
| num_filters | int | 64 | 卷积核数量 |
| kernel_size | int | 3 | 卷积核大小 |
| num_conv_layers | int | 2 | 卷积层数 |
| pool_size | int | 2 | MaxPooling 窗口大小 |
| dropout | float | 0.3 | Dropout 概率 |
| fc_hidden | int | 128 | 全连接头隐藏维度 |

### 5.5 LSTM / GRU 结构参数

| 参数 | 类型 | 默认 | 说明 |
|------|------|------|------|
| cell_type | str enum | "lstm" | lstm / gru |
| hidden_size | int | 128 | 隐藏状态维度 |
| num_layers | int | 2 | 堆叠层数 |
| bidirectional | bool | False | 是否双向 |
| dropout | float | 0.3 | 层间 Dropout（num_layers>1 时生效） |
| fc_hidden | int | 64 | 输出全连接头隐藏维度 |

### 5.6 Transformer 结构参数

> 轻量版：特征嵌入 → N 层 TransformerEncoderLayer → CLS token → 输出头

| 参数 | 类型 | 默认 | 说明 |
|------|------|------|------|
| d_model | int | 64 | 嵌入维度（需能被 nhead 整除） |
| nhead | int | 4 | 多头注意力头数 |
| num_encoder_layers | int | 2 | Encoder 层数 |
| dim_feedforward | int | 256 | FFN 中间维度 |
| dropout | float | 0.1 | Attention + FFN Dropout |
| max_seq_len | int | 512 | 位置编码最大长度（高级） |

## 六、后端实现设计

### 6.1 BaseDLTrainer（PyTorch）

```python
class BaseDLTrainer(ABC):
    device: torch.device   # auto-detect CUDA / CPU

    @abstractmethod
    def build_model(self, input_dim: int, output_dim: int,
                    arch_config: dict) -> nn.Module: ...

    def build_optimizer(self, model: nn.Module, opt_config: dict) -> Optimizer: ...
    def build_scheduler(self, optimizer, train_config: dict): ...

    def train(
        self,
        X_train, y_train, X_val, y_val,
        arch_config: dict,
        opt_config: dict,
        train_config: dict,
        epoch_callback: Callable[[int, dict], None] | None = None,
    ) -> dict:
        """
        训练循环：
          for epoch in range(epochs):
            train_loss = _train_epoch(...)
            val_loss, val_metrics = _eval_epoch(...)
            early_stopping check
            epoch_callback(epoch, {"train_loss": ..., "val_loss": ..., "val_acc": ...})
        返回最终指标 dict
        """
```

### 6.2 API 路由（/api/dl/）

```
POST   /api/dl/train                   # 提交训练任务 → DLTrainingTask
GET    /api/dl/tasks                   # 任务列表（分页）
GET    /api/dl/{task_id}/status        # 任务状态
POST   /api/dl/{task_id}/stop          # 停止任务
GET    /api/dl/models                  # DL 模型注册表（同 /api/training/models 结构）
WS     /ws/dl/{task_id}               # 实时 epoch 指标推送
```

### 6.3 Pydantic Schema

```python
class DLTrainingRequest(BaseModel):
    dataset_id:    str
    target_column: str
    model_type:    str              # mlp_dl / cnn1d / lstm / transformer

    arch_config:   dict = {}
    opt_config:    dict = {}
    train_config:  dict = {}

class DLTaskResponse(BaseModel):
    id: str
    model_type: str
    status: str
    progress: float
    current_epoch: int
    total_epochs: int
    result_metrics: dict | None
    model_path: str | None
    created_at: datetime
    # ...
```

### 6.4 WebSocket 协议

每个 epoch 推送一条 JSON：
```json
{
  "type": "epoch",
  "epoch": 5,
  "total": 50,
  "train_loss": 0.312,
  "val_loss":   0.287,
  "val_acc":    0.923,
  "lr":         0.001
}
```
训练结束推送：
```json
{ "type": "done", "status": "SUCCESS", "metrics": {...} }
```


### 7.2 深度学习配置页（/dl/config）

布局分三栏 Card：

**① 数据 & 任务**
- 数据集选择（复用现有）
- 目标列选择
- 任务类型（auto / 分类 / 回归）

**② 模型结构**
- `DLModelSelector`：类别 Tab（前馈/循环/注意力/卷积）+ 模型下拉
- `DLArchParamForm`：渲染 arch_params（复用 DynamicParamForm 逻辑）

**③ 训练控制**
- 优化器 Select（Adam/AdamW/SGD/RMSProp）
- 公共优化器参数（lr、weight_decay）
- Epochs、Batch Size、Early Stopping
- 高级展开：grad_clip、scheduler、beta1/beta2/momentum

### 7.3 深度学习监控页（/dl/monitor）

```
┌─────────────────────────────────────────────────────┐
│  任务信息卡（模型 / 数据集 / 状态 Badge / 进度条）      │
├──────────────────────┬──────────────────────────────┤
│  训练损失曲线（ECharts） │  验证损失曲线（ECharts）        │
│  train_loss 折线      │  val_loss + val_acc 折线      │
├──────────────────────┴──────────────────────────────┤
│  实时日志滚动区（epoch N / loss: x.xxx / acc: x.xxx）  │
└─────────────────────────────────────────────────────┘
```

- WebSocket 连接 `/ws/dl/{task_id}`，每 epoch append 数据点
- 使用 ECharts `setOption` 动态追加，不重绘全图

### 7.4 深度学习结果页（/dl/results）

- 分类：混淆矩阵热力图 + Precision/Recall/F1 表格
- 回归：预测 vs 实际散点图 + RMSE/MAE/R² 卡片
- 训练历史折线（完整 loss 曲线，复用监控页图表）
- 模型下载按钮（.pt 文件）

## 十、风险与决策

| 风险 | 决策 |
|------|------|
| PyTorch 包体积大（CPU~800MB） | 仅在后端安装；前端无感知 |
| 表格数据适配 LSTM/Transformer 语义不自然 | 文档说明"特征顺序即序列"，提示用户特征工程 |
| 训练时间长，前端超时 | WebSocket 解耦，任务异步；HTTP 轮询兜底 |
| GPU 依赖环境差异 | `torch.cuda.is_available()` 自动降级，日志提示当前设备 |
| 混淆矩阵数据量大 | 后端计算后只传 label 列表 + matrix 二维数组给前端 |
