# 组件规范与本轮验证

更新：2026-09-10。本轮在现有 React 技术栈中继续对齐 `power-trade`，仅实现 dark。

## 规范来源

参考天津工程 `vpp-ui-design-system`，具体以以下实现为依据：

- `itmg-dtk-base/src/style/element/button/index.less` 及 `style/theme/dark/var.css`：按钮尺寸、间距和状态。
- `itmg-dtk-base/src/style/element/table/index.less`、`pagination/index.less`、`tabs/index.less`：表格、分页与内容页签。
- `power-trade/src/standalone/components/StandaloneTabs.vue`：顶部导航页签。
- `power-trade/src/components/business/PageShell.vue`：详情返回栏和标题区。

## 统一规则

| 组件 | 本项目规则 |
| --- | --- |
| 常规按钮 | 高 32px、字号 12px、圆角 4px、左右内边距 16px、图标与文字间距 6px；相邻操作间距 16px |
| 主操作 | 新增、保存、启动使用蓝色实心按钮；普通刷新、取消、返回步骤使用描边按钮 |
| 危险操作 | 删除、停止使用危险色；确认弹层中的确认按钮保持危险色 |
| 文字操作 | 表格操作列统一无底色、无边框、无图标，保留清晰文字；禁用、加载、提示、确认与原事件回调保留 |
| 特殊控件 | 日志工具栏等纯图标按钮保留可访问名称；登录大按钮高 40px；分页和返回栏使用各自组件尺寸 |
| 搜索框 | `workspace-search` 高 32px、4px 圆角，输入区与搜索按钮共用外边框和深蓝底色；按钮宽 32px、单条竖线分隔；悬停和聚焦统一高亮，保留原生清空、回车和点击搜索 |
| 下拉选择 | 常规及 small 高 32px、4px 圆角、左右 8px 内边距；占位文字白色 60%、正常文字和箭头白色 90%，悬停/展开蓝色高亮；选项高 32px、字号 12px，选中浅蓝底；多选标签高 24px，禁用态保留独立底色和弱化文字 |
| 说明提示 | info 使用项目蓝色 `#1a8dff`：背景透明度 6%、边框 16%、图标 14px；内边距 8px 12px，正文 12px/20px、白色 60%，带标题时标题 14px、白色 90%；警告、错误与成功提示保留原有语义色 |
| 顶部页签 | 高 28px、内容高 26px、字号 12px、标题最大宽 150px；按源工程使用折线分隔、蓝色选中态；关闭全部显示文字 |
| 页签交互 | 左右滚动按钮按边界禁用；滚轮横向移动；方向键、Home、End 切换；选中页签及关闭按钮在窗口变化后保持可见 |
| 内容页签 | 14px 字号、32px 间距、2px 蓝色选中线；卡片页签统一边框和背景 |
| 表格 | 表头与普通单行最小高 48px，单元格上下 8px、左右 16px；多行内容自适应，不强制裁切；保留条纹、固定操作列、排序与选择 |
| 空态 | 空行最小高 160px，错误与无数据沿用各页面明确文案 |
| Tag | 表格内类型、模型、策略与状态使用原生 Tag；高 24px、字号 12px、左右 8px、圆角 4px、透明边框与语义色浅底；长标签最多 140px，模型与策略可悬停查看完整内容 |
| Radio.Group | 使用原生单选按钮组；高 32px、字号 12px，未选中底色 `#1c4694`、选中底色 `#1a8dff`，分隔 1px；保留键盘、禁用与 Form 绑定 |
| 统计卡片 | 复用 `MetricCard`，参考 power-trade MetricGrid 的左图标/右内容结构；高至少 112px、图标 44px、标题 14px、数值 32px，文字状态 22px；状态色用于图标，主要信息使用亮色文字 |
| 用户下拉菜单 | 深蓝浮层、最小宽 128px、4px 圆角、32px 菜单行；亮色文字，悬停/聚焦为蓝色高亮；用户按钮显示展开状态，支持 Esc 返回焦点和点击外部关闭 |
| 分页 | 页码和前后页高 32px、最小宽 32px、4px 圆角、8px 间距；当前页蓝底白字，其他页描边；右对齐，窄屏自动换行 |
| 详情顶部 | 独立 48px 返回栏，左箭头与文字间距 10px、字号 16px；下方标题区最小高 72px、标题 18px/600，操作区随可用宽度换行 |

已迁移建模任务详情、建模工作流、ML/DL 训练详情、时序详情及统一模型结果页。保留明确的返回目标、页面缓存和业务操作，不依赖浏览器历史猜测返回地址。

实现入口为 `src/theme/antd.js`、`src/styles/controls.css`、`src/styles/workspace.css`、`src/navigation/Workspace.jsx` 和 `src/components/layout/DetailHeader.jsx`。表格及分页继续使用原生 Ant Design 组件，保留调用方的状态和事件接口。

运行诊断与训练方案原本使用固定 `pageSize` 同时开放每页条数切换，导致选择会被固定值覆盖；现改用 `defaultPageSize`，由组件保留用户的选择。

- 单元测试：29 个文件、250 项全部通过。
- ESLint：零错误、零警告。

- 静态核对所有“操作”列中的按钮均为带文字的 link 按钮，无图标属性或空标签。
- 桌面浏览器验证：返回导航、操作列文字、危险色确认弹层、页签键盘操作、选中页签完整可见、第二页状态保留、每页条数切换及切换页签后的保留。
- 六种详情入口均正常渲染，返回栏实测高 48px；无整页水平溢出。
- 390 × 844 窄屏验证：详情操作正常换行；页面宽度 390px，分页边界处于页面内部。

## 截图反馈后的修正与补测（2026-09-10）

本节补充上一轮未覆盖的多页省略号与单选控件场景。

- Tag：修正 Ant Design 预置颜色覆盖项目配色的问题；移除散落的字号/内边距覆盖；运行诊断孤立任务、时序任务及部署表格的状态统一为 Tag，补齐训练列表中的模型、类型标签。建模任务、训练方案、运行诊断实测标签高 24px、圆角 4px，成功/运行中/分类/模型族等颜色与公共规范一致。
- 分页：原先通用 `.ant-pagination-item-link` 描边规则影响跳转用的行内链接，导致省略号下落一行。描边现在仅作用于上一页/下一页；跳转链接与内部容器固定为 32px，保留悬停双箭头。数据预览使用 100 行样本，在第 6/20 页验证双侧省略号对齐、跳至第 11 页、首尾页按钮禁用及实际数据切换。训练方案标准分页也在第 6 页验证两侧省略号。
- 训练方案表格：补齐列宽和横向滚动，方案名列保持 220px，避免名称挤成竖排；每页条数切换有效。390×844 下页面宽度为 390px，列表分页与预览弹窗分页均在容器内换行，省略号保持在各自 32px 页码行内。
- Radio.Group：替换训练方案筛选、模型族与 SHAP 原有 Segmented；分类/回归筛选均返回对应 50 条样本，方向键可切换。混合模型选择 ML+DL 后切到 ML，DL 行被移除；实际模拟提交为 `model_family: "ml"`、仅 ML 候选模型、`dl_config: {}`，创建成功。
- SHAP：聚合数据时 Beeswarm/依赖散点为禁用态，按钮仍高 32px；含样本数据时三项启用，切换 Beeswarm 后生成图表，方向键切到依赖散点后出现特征选择控件。
- 弹层交互：修正公共 portal 样式覆盖 Drawer 根容器的 `pointer-events`，避免抽屉关闭后透明容器拦截点击。回归验证关闭诊断抽屉后可切换“孤立任务”，并分页到第 2 页（12 条）。

测试夹具 `scripts/integrity-server.mjs` 保留 100 行数据预览、100 条分类/回归方案、独立 ML/DL 模型注册表及 SHAP 聚合/样本两种状态，以便复测。本节的创建操作仅写入本机内存夹具。

最终复核：29 个测试文件、250 项测试通过；ESLint 零错误/警告；生产构建及 `git diff --check` 通过。控制台仅观察到已有 Card 属性弃用提示，构建仍保留原有大包提示。临时浏览器与模拟服务已关闭，本地 3000 服务未改动。

## 统计卡片可读性调整（2026-09-10）

将截图中的深色小标题、彩色数值与居中排列改为统一的 `components/layout/MetricCard.jsx`。背景使用 `--surface-1`，边框使用 `--border-strong`，标题与数值使用 `--text-primary`；实测文字与卡片背景对比度约 10.72:1。颜色在左侧图标区表达状态，避免成功绿、失败红直接作为低对比度正文。相比源工程 104px/12px/26px 的尺寸，根据本次可读性反馈提高至 112px/14px/32px。

覆盖时序列表、时序详情、模型部署（含 Chronos 状态）、建模列表和建模详情的同类概览卡片。保留原有统计取值与请求逻辑；零值显示 `0`，缺失值显示 `—`，文字状态使用独立字号并允许长文本换行。

验证：上述五类页面在桌面正常显示；390×844 下四项统计为两列，卡片无水平溢出；空数据为四个清晰的 `0`，刷新加载与模拟接口错误期间卡片尺寸和颜色稳定。29 个测试文件/250 项测试、ESLint 和构建通过，构建保留已有的大包提示。

## 下拉组件修正与验证（2026-09-10）

截图中的任务类型与状态筛选使用原生 Select，但此前没有组件级主题，占位文字与箭头均继承白色 25% 的默认值，容易被误认为禁用状态。现通过 `src/theme/antd.js` 的 Select 配置统一尺寸、颜色、菜单和多选标签；`src/styles/controls.css` 补齐箭头展开、清空和禁用状态。主题同步作用于页面、分页、弹窗及 body portal，未改动业务回调、接口或数据处理。

- 运行诊断：孤立任务选择“预测”后正确回显，清空恢复占位文字；隔离接口记录包含 `kind=predict`，清空后去掉该参数。全部 Run 选择“成功”发送 `status=SUCCESS`，清空后恢复无状态参数。夹具不执行这些服务端筛选，本项验证的是交互与请求参数。
- 训练方案：分页从 10 条切换到 20 条，表格实际显示 20 行。新建弹窗内方向键及回车可选择“回归”；候选模型按现有模型标识搜索 `random`，选择后标签高 24px、控件高 32px，移除后恢复占位提示，原有必填校验红框正常显示。
- 390×844 窄屏：弹窗下拉框和菜单均位于横坐标 32–186px，未超出视口。Esc 收起菜单并保留输入焦点。
- 设置页：禁用的深色主题选择框仍不可编辑，文字/箭头为白色 26%；正常语言选择框为白色 90%，两者高度均为 32px。
- 本轮 29 个测试文件、250 项单元测试、ESLint、生产构建及 `git diff --check` 通过；构建保留已有的大包提示。浏览器验证使用本机内存夹具，未操作真实业务数据。

## 说明提示轻量化（2026-09-10）

info Alert 原先继承青色的默认深色算法，背景偏绿发黑，带描述时图标和留白也过大。现为 Alert 单独指定蓝色信息提示配色，并只对 `.ant-alert-info` 收紧尺寸；警告、错误和成功样式不受该覆盖影响。孤立任务说明移除与当前页签重复的标题，保留任务范围与训练任务入口说明。

浏览器实测：1280×720 下孤立任务提示高 38px，背景为 `rgba(26,141,255,.06)`、边框为 `rgba(26,141,255,.16)`，图标为项目主蓝；390×844 下完整换行为 98px，页面无水平溢出。部署页“模型下载说明”保留标题与描述，高 60px，颜色与普通说明一致。29 个测试文件/250 项测试、ESLint、生产构建及 `git diff --check` 通过；构建保留原有的大包提示。
