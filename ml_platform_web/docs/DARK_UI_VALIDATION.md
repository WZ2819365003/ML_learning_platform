日期：2026-09-09

2026-09-10 补充：按钮、页签、表格、分页与详情返回栏已再次按源工程调整，规范与本轮验证见 [组件规范与验证](UI_COMPONENT_SPEC.md)。

## 交付范围

保留 React 18、React Router 6、Ant Design 5 和 ECharts。参考天津工程的 `vpp-ui-design-system`、`power-trade/src/standalone`、业务组件与基座 dark tokens，在本项目内实现对应组件和交互。只提供 dark 主题；报告打印保留纸张配色。

- 顶栏 64px、导航页签栏 28px；侧栏 235px，小屏桌面 220px，折叠 64px。
- 主色 `#1a8dff`、页面背景 `#061a3e`、面板 `#0a2558`、表头 `#113883`，统一 4px 圆角。
- 表格、表单、按钮、状态标签、弹窗、抽屉、图表与在线报告统一样式；保留原业务字段、操作入口和 API 请求契约。
- 菜单保留数据、建模、时序、系统设置，补齐训练方案入口。
- 新增可关闭多页签、左右滚动、关闭全部、刷新后导航恢复。
- 按任务 ID 和结果 family 隔离页面缓存；筛选、分页、滚动、草稿和内部选项卡保留。
- 关闭清理页面实例；未保存内容确认；上传/保存期间阻止关闭。关闭页签不会取消后端训练。
- 隐藏页面暂停轮询与日志连接，激活后恢复；图表自动适配恢复后的尺寸。
- 弹层归属各自页签；打印文档只由当前页签提供。
- 退出/401 清理会话页签缓存，避免过期会话被草稿离开提示阻挡。

## 真实接口检查与验证边界

原开发服务的 `.env.local` 仍为 `VITE_API_TARGET=http://203.176.93.249:18081`。补齐 `/health` 代理后：

- `http://127.0.0.1:3000/health` 返回 **200**。
- 未带登录令牌请求 `http://127.0.0.1:3000/api/v3/runs/` 返回 **401**，符合鉴权预期。
- `/v3/runs` 是前端页面地址；API 经 `/api/v3/runs/` 调用。

本次完整性验证针对前端页面、路由、组件状态、请求交互和现有单元测试。创建、上传、时序提交、500/401 等写入和异常场景在模拟接口执行；没有执行真实模型训练、真实部署、删除真实业务数据，也未验证后端算法结果。打印已验证 DOM 内容、图表及纸张配色，未执行操作系统打印对话框中的实际 PDF 保存。

仓库原有 4 个 E2E 文件默认连接 3000 并写真实后端数据，本次未直接运行这组真实数据测试。最终回归采用 CUA 浏览器交互与隔离模拟 API；上述范围不等同于后端生产环境验收。

## 复现

```bash
nvm use
npm ci --include=optional
npm run test:unit
npm run lint
npm run build
npm run dev:integrity
```

最后一条命令同时启动本机 3300 页面和 3901 模拟 API。模拟状态可通过 `POST http://127.0.0.1:3901/__test/state` 设置，例如 `{"error":"/v3/runs"}`、`{"empty":true}`、`{"unauthorized":true}`；`GET /__test/requests` 返回请求和 WebSocket 事件记录。停止进程即清除模拟数据。普通 `npm run dev` 继续使用项目真实代理配置。
