# ML Platform 品牌标识指南

## 1. 品牌概述

ML Platform 是一个专业的机器学习平台，为用户提供数据管理、模型训练、监控和可视化等功能。品牌定位为专业、现代、可靠，旨在为用户提供直观、高效的机器学习工作流程。

## 2. 颜色方案

### 主色调
- **主色**: #1890ff (科技蓝) - 代表专业、创新和可靠性
- **辅助色**: #52c41a (成功绿) - 用于成功状态和正面反馈
- **警告色**: #faad14 (警告黄) - 用于警告状态和提醒信息
- **错误色**: #f5222d (错误红) - 用于错误状态和负面反馈

### 中性色
- **背景色**: #f5f5f5 - 用于页面背景
- **卡片背景**: #ffffff - 用于卡片和容器
- **边框色**: #e8e8e8 - 用于分割线和边框
- **次要文本**: #8c8c8c - 用于次要信息
- **主要文本**: #262626 - 用于主要内容

### 渐变色
- **主渐变**: linear-gradient(135deg, #1890ff, #36cfc9) - 用于强调元素和按钮
- **背景渐变**: linear-gradient(135deg, #f0f9ff, #e6f7ff) - 用于页面背景和头部

## 3. 排版

### 字体
- **主要字体**: -apple-system, BlinkMacSystemFont, 'Segoe UI', 'Roboto', 'Oxygen', 'Ubuntu', 'Cantarell', 'Fira Sans', 'Droid Sans', 'Helvetica Neue', sans-serif
- **代码字体**: source-code-pro, Menlo, Monaco, Consolas, 'Courier New', monospace

## 4. 组件设计

### 按钮
- **主要按钮**: 填充主色，白色文字，圆角4px，悬停效果
- **次要按钮**: 白色背景，主色边框和文字，圆角4px
- **危险按钮**: 填充错误色，白色文字，圆角4px
- **文本按钮**: 无背景，主色文字，悬停时显示下划线

### 卡片
- **圆角**: 8px
- **阴影**: 轻微阴影 (0 2px 8px rgba(0, 0, 0, 0.09))，悬停时加深
- **边框**: 1px 实线，使用边框色
- **内边距**: 24px

### 表单
- **输入框**: 圆角4px，聚焦时主色边框，占位符使用次要文本色
- **标签**: 14px，主要文本色，位于输入框上方
- **错误提示**: 12px，错误色，位于输入框下方

### 图表
- **配色**: 使用主色及其衍生色，确保颜色对比度和可读性
- **风格**: 简洁、现代，注重数据可读性
- **交互**: 悬停显示详情，支持缩放和导出

### 图标
- **风格**: 线性图标，简洁现代
- **大小**: 16px (默认)，24px (大)，12px (小)
- **颜色**: 主要文本色 (默认)，主色 (强调)

## 5. 布局设计

### 整体布局
- **侧边栏宽度**: 240px (展开)，80px (折叠)
- **顶部导航栏高度**: 64px
- **主内容区边距**: 24px
- **卡片间距**: 16px

### 响应式断点
| 设备类型 | 屏幕宽度 | 布局调整 |
|----------|----------|----------|
| 桌面端 | ≥1200px | 完整布局，侧边栏展开 |
| 平板端 | 768px-1199px | 侧边栏可折叠，内容区域自适应 |
| 移动端 | <768px | 侧边栏隐藏（通过菜单按钮展开），内容区域单列布局 |

## 7. 设计原则

### 一致性
- 确保所有页面和组件使用统一的颜色、字体和间距
- 保持交互模式的一致性，减少用户学习成本

### 清晰性
- 信息层次分明，突出重要内容
- 使用简洁明了的语言和图标
- 提供清晰的视觉反馈

### 易用性
- 减少操作步骤，简化用户流程
- 提供直观的导航和操作界面
- 确保响应式设计，适配不同设备

### 美观性
- 采用现代、简洁的设计风格
- 注重细节，提升用户体验
- 保持视觉平衡和和谐
