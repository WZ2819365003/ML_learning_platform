# ML Platform 前端设计文档

## 1. 项目概述

本前端项目是为机器学习平台（ML Platform）开发的用户界面，旨在为用户提供直观、高效的机器学习模型训练、管理和可视化功能。前端将与后端API进行交互，实现数据上传、模型训练、实时监控、结果可视化等核心功能。

## 2. 技术栈选择

| 类别 | 技术 | 版本 | 用途 |
|------|------|------|------|
| 框架 | React | 18+ | 前端核心框架 |
| 构建工具 | Vite | 5+ | 快速构建和热更新 |
| UI组件库 | Ant Design | 5+ | 提供美观、易用的UI组件 |
| 图表库 | ECharts | 5+ | 数据可视化图表 |
| 状态管理 | Redux Toolkit | 2+ | 全局状态管理 |
| HTTP客户端 | Axios | 1+ | API调用 |
| WebSocket | Socket.io | 4+ | 实时数据推送 |
| 样式解决方案 | Tailwind CSS | 3+ | 实用优先的CSS框架 |
| 代码规范 | ESLint + Prettier | - | 代码质量保证 |

## 4. 核心功能模块设计

### 4.1 数据管理模块

**功能点：**
- 拖拽上传数据文件（CSV/Parquet）
- 数据预览和基本统计信息
- 数据集列表管理
- 数据集删除

**设计要点：**
- 拖拽上传区域：醒目、直观，支持文件拖放
- 数据预览表格：分页显示，支持列排序
- 统计信息卡片：显示行数、列数、数据类型等关键信息

### 4.2 训练配置模块

**功能点：**
- 选择数据集
- 选择目标列
- 选择模型类型（RandomForest、XGBoost等）
- 配置模型超参数
- 选择评估指标
- 启动训练任务

**设计要点：**
- 步骤式向导：引导用户完成训练配置
- 动态表单：根据选择的模型类型显示相应的超参数配置
- 实时验证：验证用户输入的有效性

### 4.3 训练监控模块

**功能点：**
- 训练任务列表
- 实时训练进度和指标
- 实时日志流
- 训练任务控制（停止）

**设计要点：**
- 实时图表：使用ECharts绘制实时更新的指标曲线
- 进度条：直观显示训练进度
- 日志面板：支持滚动、搜索和过滤

### 4.4 结果可视化模块

**功能点：**
- 混淆矩阵
- ROC曲线
- 特征重要性
- SHAP可解释性分析
- 学习曲线

**设计要点：**
- 选项卡式布局：方便用户切换不同的可视化结果
- 交互式图表：支持缩放、悬停查看详情
- 导出功能：支持导出图表为图片

### 4.5 模型管理模块

**功能点：**
- 已训练模型列表
- 模型详情查看
- 多模型对比
- 模型删除

**设计要点：**
- 表格展示：清晰显示模型基本信息和性能指标
- 对比图表：使用雷达图或柱状图对比多个模型
- 操作按钮：提供查看、对比、删除等操作

- 配色：使用主色及其衍生色

- 交互：悬停显示详情，支持缩放

## 7. 响应式设计

### 7.1 断点设计

| 设备类型 | 屏幕宽度 | 布局调整 |
|----------|----------|----------|
| 桌面端 | ≥1200px | 完整布局，侧边栏展开 |
| 平板端 | 768px-1199px | 侧边栏可折叠，内容区域自适应 |
| 移动端 | <768px | 侧边栏隐藏（通过菜单按钮展开），内容区域单列布局 |

### 7.2 适配策略

- 使用Flexbox和Grid布局实现响应式设计
- 关键组件（如数据表格）在小屏幕上自动调整为卡片式布局
- 图表在小屏幕上简化显示，保持核心信息清晰
- 触摸友好的交互设计，确保在移动设备上的良好体验

## 8. 性能优化

### 8.1 前端性能优化

- 代码分割：使用React.lazy和Suspense实现组件懒加载
- 缓存策略：缓存API响应和静态资源
- 虚拟滚动：处理大量数据列表
- 图表优化：大数据集图表采用数据采样和按需渲染
- 减少重渲染：使用React.memo、useMemo和useCallback优化组件渲染

### 8.2 加载体验

- 骨架屏：在数据加载过程中显示骨架屏
- 进度指示器：显示文件上传和训练任务的进度
- 错误处理：友好的错误提示和恢复机制
- 离线支持：关键功能的离线访问能力

## 11. 技术风险与应对策略

| 风险 | 影响 | 应对策略 |
|------|------|----------|
| WebSocket连接不稳定 | 实时监控功能受影响 | 实现断线重连机制，添加连接状态检测 |
| 大数据集处理性能 | 数据预览和图表渲染卡顿 | 实现数据分页、虚拟滚动、数据采样 |
| SHAP计算耗时 | 页面加载缓慢 | 添加加载状态，限制计算样本数，考虑后台计算 |
| 浏览器兼容性 | 部分功能在旧浏览器中不支持 | 明确浏览器支持范围，添加兼容性提示 |
| API响应延迟 | 用户操作反馈不及时 | 添加加载状态，实现乐观更新，优化API调用 |

## 12. 总结

本设计方案为ML Platform前端项目提供了全面的技术架构和设计指导，涵盖了从技术选型、页面结构、功能模块到视觉设计的各个方面。通过使用React、Ant Design和ECharts等现代前端技术，结合合理的架构设计和性能优化策略，将为用户提供一个美观、高效、易用的机器学习平台界面。

设计方案充分考虑了后端API的对接需求，确保前端能够与后端系统无缝集成，实现完整的机器学习工作流程。同时，响应式设计和性能优化措施确保了在不同设备和网络环境下的良好用户体验。
